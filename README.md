# Karma Omut — Tattoo Collective

Лендинг тату-коллектива **«Карма Омут»** (Волгоград).

- Один самодостаточный `index.html` (весь CSS и JS внутри, без сборки).
- Тёмная тема: чёрный / белый / красный.
- Реальный логотип-хамса в hero (реагирует на курсор), реальные фото работ и интерьера.
- Анимации в стиле lumos: маскированное раскрытие заголовка, count-up цифр, бегущая строка, reveal-на-скролле, кастомный курсор.
- Форма записи → отправка в WhatsApp.
- SEO: JSON-LD (TattooParlor), Open Graph, иконки, `sitemap.xml`, `robots.txt`.
- Адаптив (мобилка/планшет/десктоп), поддержка `prefers-reduced-motion`.

## Структура

```
index.html            — главная страница
privacy.html          — политика конфиденциальности (152-ФЗ)
site.webmanifest      — манифест PWA (иконка на экран телефона)
robots.txt / sitemap.xml
img/                  — логотип, иконки, og-картинка, фото работ (WebP)
```

## Запуск локально

Просто открыть `index.html` в браузере. Для корректной загрузки `site.webmanifest`
лучше поднять локальный сервер:

```bash
npx serve .
# или
python -m http.server 8000
```

## Деплой на GitHub Pages

1. Создать репозиторий на GitHub и запушить содержимое (см. инструкцию ниже).
2. Settings → Pages → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)`.
3. Сайт будет доступен по `https://<user>.github.io/<repo>/`.

- В `index.html`/`sitemap.xml`/`robots.txt` заменить `https://karma-omut.ru/` на реальный домен.

- Заменить плейсхолдеры мастеров и обобщённые отзывы на реальные при наличии данных.
- Подключить приём заявок (Telegram-бот / e-mail), если WhatsApp недостаточно.
